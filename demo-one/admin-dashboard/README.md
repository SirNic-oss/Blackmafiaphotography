# Fashion-Fit Admin Dashboard

Admin panel for managing products, orders, customers, and analytics for the Fashion-Fit store.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3001](http://localhost:3001).

## Environment

Copy `.env.local` and set `NEXT_PUBLIC_API_URL` to your backend URL (default: `http://localhost:5000`).

## Demo Login

Use any email and password on the login page for demo access.
